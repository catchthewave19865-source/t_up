# 未成年利用・保護者同意書のWeb化

スタジオDancersで紙とPDFで運用している「未成年者のご利用に関する保護者同意書」を、
ブックルの機能として電子化するための設計とスキーマ。

このディレクトリはブックル本体のリポジトリへ移植する前提の下書きです。
本体（`rental-booking`）に接続できしだい、そちらへ実装します。

| ファイル | 内容 |
| --- | --- |
| `consent-text.v1.ja.md` | 同意文言 v1。紙版から起こしたもの。改版のたびに版を上げる |
| `types.ts` | Firestore のデータモデル |
| `firestore.rules.snippet` | Firestore セキュリティルール |

## 設計上の前提

現行データ（Firestore）を確認したうえでの前提です。

- 会員は `users/{lineUserId}` で管理され、LINE ユーザー ID がドキュメント ID を兼ねる
- すべてのドキュメントがマルチテナント識別子 `orgId` を持つ
  （スタジオDancers は `P472wbOrUKhQ6DGLPOBTXJptXwt2`）
- LINE 配信の基盤（`lineUsers` 3,064件）と書類の LINE 送付（`lineDocumentDeliveries`）、
  SMS 認証（`phoneVerifications`）はすでに存在する
- 保護者はブックルのアカウントを持たない。使い捨てトークン付き URL だけが入口になる

## 着手前に解いておくべき問題

### 1. 会員データに生年月日がない

`users` コレクションに生年月日にあたるフィールドが存在しません
（保持しているのは `name` / `phone` / `email` / `lineUserId` / `orgId` 程度）。

つまり **「未成年会員の予約を自動検知する」ことが今のデータではできません。**
同意書フォームだけ作っても、いつ誰に送るべきかを機械的に判定できないため、
運用が回りません。次のいずれかが先に必要です。

1. **予約時の自己申告**（推奨・すぐ入る）
   予約フローに「未成年の方のみでご利用ですか？」を追加し、
   はいなら同意書のフローへ入る。既存会員にも即日効く。
2. **管理画面で未成年フラグを手動で立てる**
   人数が限られるなら現実的。ただし取りこぼしが起きる。
3. **会員登録で生年月日を必須化**
   本筋だが、既存 2,142 件の会員には遡って効かない。

推奨は 1 と 2 の併用です。そのうえで、同意書フォームで取得した
利用者の生年月日を `users` に書き戻せば、以後は自動判定へ移行できます。

### 2. 本人確認書類の保存に既存の仕組みを流用できない

`lineDocumentDeliveries` の領収書画像は `?alt=media&token=...` 形式の
恒久ダウンロード URL で保存されています。この URL は知っている者が
無期限に開けます。領収書なら許容範囲でも、本人確認書類には使えません。

本人確認書類は次の扱いにします。

- 非公開バケットに保存し、恒久 URL を発行しない
- 閲覧のたびに Cloud Functions が数分で失効する署名付き URL を発行する
- 画像パスは `minorConsents/{id}/sensitive/idDocument` に隔離し、
  クライアントからは管理者であっても読めなくする
  （Firestore ルールはフィールド単位の読み取り制御ができないため）
- 誰がいつ開いたかを `minorConsentAccessLogs` に残す
- **承認から 90 日で画像を自動削除**し、「確認済み」の事実と確認者名だけを残す

### 3. 「免許証」に限定しない

運転免許を持たない保護者は珍しくありません。`IdDocumentType` は
免許証・マイナンバーカード（**表面のみ**）・パスポート・在留カード・
健康保険証から選ぶ形にしています。

- マイナンバーカードは個人番号が写ると受領自体が問題になるため表面のみ
- 免許証番号と本籍地は同意の証明に不要。撮影ガイドで隠すよう促し、
  写り込んだ場合は保存前にマスキングする
- 健康保険証を使う場合は記号番号のマスキングが前提

## 未確定の設計判断

既定値としてこの内容で組んでいます。変更する場合は指示してください。

| 項目 | 既定値 |
| --- | --- |
| 本人確認書類の種別 | 5種から選択式（免許証に限定しない） |
| 書類画像の保管 | 承認から 90 日で自動削除。確認済みフラグと確認者は永続 |
| 同意の有効期限 | 取得から 1 年、または 18 歳到達日の早い方 |
| リンクの有効期限 | 発行から 72 時間、一度使用したら無効 |
| 保護者への配信 | 会員の LINE へ送って転送してもらう／保護者へ SMS 直送の両対応 |
