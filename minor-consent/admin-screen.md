# 管理画面と配信の導線

同意書フォームを作っても、**保護者がそこへ辿り着けなければ運用は回りません。**
申告から提出までの導線と、提出がない場合の再送をここで定義します。

## 1. 申告からフォームが届くまで

`users` に生年月日が無いため、未成年の検知は自己申告から始めます。

1. **予約フォームに申告欄を置く**
   「未成年の方のみでご利用ですか？（保護者の同伴がない場合）」のチェックを追加。
   チェックが入ると、8:00〜21:00 以外の時間帯は選べなくなります。

2. **予約確定と同時にリンクを発行する**
   Cloud Function が `minorConsents`（`status: 'pending'`、`trigger.source: 'self_declared'`、
   `trigger.bookingId` に予約 ID）と `minorConsentLinks`（72時間有効）を作ります。

3. **その場と、あとから、の両方で届ける**

   | 届け先 | 内容 |
   | --- | --- |
   | 予約完了画面 | 「保護者の方に同意書のご記入をお願いします」＋リンクと共有ボタン |
   | 会員の LINE | 同じリンク。「保護者の方へ転送してください」と明記 |
   | 予約完了メール | LINE 未連携の会員でも詰まないための保険 |

   **予約完了画面にも必ず出すこと。** LINE 配信だけに頼ると、
   LINE を未連携の会員や通知に気づかない会員がそこで止まります。

4. **未提出なら自動で追う**
   利用日の 3 日前と前日にリマインドを自動送信。
   利用日までに提出がなければ、予約を「保護者同意待ち」として扱います。

## 2. 提出がない場合の再送

管理画面に **「同意書」タブ** を置き、対応が必要なものだけを上に出します。

### 一覧

`status` が `pending` / `expired` / `rejected` のものを、利用日が近い順に並べます。
各行に出す情報:

- 会員名 / 利用日時 / 店舗
- 状態（未提出・期限切れ・差し戻し）
- **最終送信日時と送信回数**（`delivery.lastSentAt` / `delivery.sendCount`）
- 送信経路（LINE / SMS / メール）

### 再送ボタン

**各行に「再送」、一覧の上部に「未提出者へ一括再送」。**

「再送」は案内一式をもう一度送るものです。フォームの URL だけでなく、
説明文・8:00〜21:00 の制限・保護者の方へのお願いを含めた全体を送り直します。

押したときの挙動:

1. **新しいトークンを発行し、古いトークンを失効させる**
   （`revokedAt` と `supersededByToken` を立てる）。
   古いリンクが生き続けると、保護者がどちらを開いたのか分からなくなります。
   同意記録 `consentId` は使い回すので、履歴は 1 件にまとまります。

2. **送信先を選ばせる** — 会員の LINE / 保護者の SMS / 両方。
   保護者の電話番号がまだ無い（＝一度も提出されていない）場合は SMS を選べません。
   一度差し戻した相手には、SMS 直送のほうが届きます。

3. **送信履歴を残す** — `minorConsentNotifications` に
   誰が・いつ・どの経路へ・成功したかを記録します。

### 連投を防ぐ

保護者に何度も通知が飛ぶのは事故です。

- 最終送信から **10 分間は再送ボタンを押せない**（`delivery.resendAvailableAt`）。
  ボタンは無効化し、「あと◯分で再送できます」と理由を出します。
- 送信回数が 5 回を超えた相手は、一括再送の対象から自動で外します。
  行には「電話で連絡してください」と表示します。届かない理由が
  通知ではないところにあるためです。
- 一括再送は**実行前に対象件数と宛先を一覧で見せて確認**を取ります。
  誤操作で数十人に一斉送信されるのを防ぎます。

### 失敗を握りつぶさない

LINE のブロックや電話番号の誤りで送信が失敗したら、`result: 'failed'` と
理由を記録し、一覧に警告として出します。「送ったつもり」で利用日を
迎えるのがいちばん困ります。

## 3. 本人確認書類だけが未提出の場合

保護者が署名まで終えて書類の撮影で離脱した、というケースがあり得ます。
この場合は最初からやり直させず、**書類の提出だけを求めるリンクを送ります。**
入力済みの内容は保持し、撮影の手順から再開できるようにします。
